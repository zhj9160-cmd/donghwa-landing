Firebase 콘솔 · 약 10분

설정 5단계

단계콘솔 메뉴할 일
1프로젝트 추가이름 입력 · 애널리틱스 끄기
2빌드 → Realtime Database데이터베이스 만들기 · 위치 싱가포르 · 잠금 모드
3빌드 → Authentication이메일/비밀번호 사용 · 강사 계정 추가 · UID 복사
4Realtime Database → 규칙database.rules.json 붙여넣기 · 게시 · 데이터에 admins/UID = true
5프로젝트 설정 → 내 앱(웹)웹 앱 등록 · 구성 값 firebase-config.js 에 붙여넣기
firebase-config.js

구성 파일 · 값 붙여넣기만

window.FIREBASE_CONFIG = { apiKey:'…', authDomain:'…', databaseURL:'https://…firebasedatabase.app', projectId:'…', appId:'…' }; window.DECK_ID = 'my-lecture-0927';
  • apiKey: 비밀번호 아님 · 웹 앱에 공개되는 식별 정보
  • 보안: 규칙 파일이 담당 · 쓰기는 admins 목록 계정만
  • DECK_ID: 강의마다 다른 이름 · 한 프로젝트로 여러 강의
database.rules.json
